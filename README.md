# Hyperfocus

We're building an **AI Ops Team** for multi-channel e-commerce brands.

[**hyperfocus.tech**](https://hyperfocus.tech) unifies TikTok Shop, Amazon, and Shopify into one P&L — with AI that finds profit leaks, prevents stockouts, and prepares actions you just confirm.

## What we open-source here

Tools and libraries we build internally:

- **Infrastructure** — deployment scripts, CI/CD configs, cloud utilities
- **Data pipelines** — ETL for e-commerce platforms (TikTok, Amazon, Shopify)
- **AI components** — agents, prompts, evaluation tools
- **UI kit** — glassmorphism components, charts, dashboard blocks

## Core Products

| Product | What it does |
|---------|--------------|
| **Fee Decoder** | Finds hidden fees and overcharges |
| **Affiliate Police** | Tracks creator ROI, catches ghost influencers |
| **Viral Guard** | Predicts stockouts before they happen |
| **Unified P&L** | One dashboard for all channels |
